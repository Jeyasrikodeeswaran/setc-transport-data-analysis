# Tamil Nadu Public Transport Data Analysis

## Overview
This project focuses on analyzing Tamil Nadu State Express Transport Corporation (SETC) public transport datasets to identify service distribution patterns, accessibility gaps, operational frequency trends, and transport hub connectivity.

The analysis is performed as part of an internship project focused on e-governance and public service analytics.

---

## Objectives
- Analyze district-wise transport service distribution
- Identify underserved and high-service regions
- Study route frequency and transport hub connectivity
- Examine operational scheduling patterns
- Generate insights for accessibility and planning

---

## Dataset
Source:
- SETC Bus Routes, Services and Timings Dataset
- Open Government Data (OGD) Platform India

Dataset includes:
- Depot names
- Route numbers
- Source & destination
- Route length
- Service frequency
- Departure timings
- Service types
